# gaze 与 PSM xcorr：修复后的全量重跑

本报告使用修复后的完整 84 条记录。原先 66 条记录的旧报告已随旧输出保存在 `outputs/gaze_psm_xcorr_before_input_fix_20261027/`。

## 修复及验证

- 科学计数法纳秒时间戳用 Decimal 精确解析，转换相对秒之前不经过 float。
- 状态码按数值等价处理：2、2.0、2e0 等价；0 等无效状态仍排除。
- 缓存版本升级为 4，旧 gaze 数组不再复用。仅在源文件指纹、参数和原始帧/时间一致时复用旧 mask 质心；全部 gaze 与 QC 重新生成。
- 39 项测试通过，包括纳秒精度、raw/allocation 浮点状态码、失效缓存恢复、无效 gaze 显式报错，以及三名模拟参与者下串行/并行随机配对与 bootstrap 结果完全一致。
- 84/84 条提取成功、没有 quality 错误；84/84 条均可计算左右工具的全任务位置曲线。Task A 33 条，Task C 51 条，同样的 11 位新手。
- 全部 84 份新缓存指纹已与现有源文件/参数核对。18 条之前未有效纳入的记录已恢复。原先可用 66 条记录的峰值 r 与时延最大变化均为 0。
- 维持旧统计配置：41 Hz、±2 s、80 ms 平滑、1000 次新手 bootstrap、100 次异人同任务参考、50 px 空间容差；8 个工作进程只改变运行速度，不改变统计方法或权重。

## 对研究问题的回答

> 以完整 84 条记录、同样的 11 位新手为基础，gaze 与 PSM 质心的位置轨迹呈任务和阶段相关的时延。Task A 右工具约有 341 ms 的 gaze 领先，Task C 右工具约有 171 ms 的 gaze 滞后，配对任务差约为 −512 ms。Task A transfer 和 Task C reach string 的右工具具有较清楚的正时延模式，但不存在所有工具、任务和阶段统一的 gaze 提前时间。空间对应比例有限，且输入是 raw gaze、工具位置是整体 mask 质心，因此这些 xcorr 结果不能直接等同于 fixation 首次到达同一工具尖端目标的时间差。
