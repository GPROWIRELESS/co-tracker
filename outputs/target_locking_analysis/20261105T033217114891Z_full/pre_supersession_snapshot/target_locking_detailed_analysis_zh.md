# Target Locking 详细结果解读：五模型、真实 gaze 与 SimNow 表现

**分析批次：** `20261105T033217114891Z_full`  
**主分析：** target / 双侧 gripper 半径均为 50 px；有效时长加权；参与者为统计单位。  
**报告依据：** 本批次已保存的逐录像、逐阶段汇总及 10,000 次参与者 bootstrap 结果。文中百分比为占有效时间的比例，pp 表示百分点；区间为 95% bootstrap 区间。

## 1. 最值得保留的结论

1. **Task A 与 Task C 的差别，主要体现在 gripper 与重叠区域，而非绝对 target 占用。** 全量真实 gaze 的 target 占用分别为 24.89% 和 24.60%，非常接近；gripper 占用却分别为 9.45% 和 23.28%。因此 A 的相对目标偏好 C=0.767、C 任务的 C=0.514，不能解释为“做 Knot-tying 时不看目标”。
2. **五个模型都没有完整复现真人的空间行为。** Task A 中所有模型都明显低估 target 占用；single_task 的占用量最接近真人，但并未同时取得最好的逐帧命中。Task C 中 single_task 最接近全任务 target 占用，spd_zero_shot 的 C 误差较小，但其逐帧 target 不一致率反而最高。不能用一个 C 值给模型排出全面优劣。
3. **全量 11 人数据不支持“相对 target 偏好越高，SimNow 分数越高”的普遍关系。** A 的 C–Score Spearman ρ=0.036，C 的 ρ=−0.174，区间都很宽。A 五人测试子集的 ρ=0.900 是明显不同的子集现象。
4. **阶段比全任务平均更有解释力，但覆盖差异很大。** Task A 的抓环、放环是主要 target 占用阶段；Task C 的 Wrap 有明显 target–gripper 重叠。Cinch 只有少量可用标注，Thread 的模型配对 C 往往只剩一个人，不能据此判断模型优劣或技能机制。
5. **学习轮次结果也不符合单一的“更多 target locking = 更熟练”叙事。** 两任务的第 1→3 轮分数均提高；A 的 C 没有明确变化，C 任务的 C 和绝对 target 占用反而下降，gripper 与 overlap 的变化区间均跨零。更合适的解释是：这些指标的意义取决于任务、阶段及注视位置，不能统一写成“越高越好”。

## 2. 数据范围、比较对象与指标读法

### 2.1 两套样本回答不同的问题

`real_all` 使用全量 novice 录像，适合描述真实行为及其与表现的关系；`paired_test` 只使用五模型都覆盖的同一批测试录像和同一批有效帧，适合直接比较模型与真人。不能将 paired_test 的模型结果直接减去 real_all 的 gaze 均值。

|---|---|---|---|---|---|---|
| real_all | A | 11 | 33 | 369,366 | 8668.07 | 33/33 |
| real_all | C | 11 | 51 | 338,323 | 8057.63 | 50/51 |
| paired_test | A | 5 | 5 | 58,893 | 1256.04 | 5/5 |
| paired_test | C | 5 | 5 | 36,267 | 837.81 | 5/5 |

84 段录像与 50 份预测均成功读取、对齐；四分类占用守恒、面积守恒、C 零分母处理、共同帧支持等核验均通过。Task C 的 51 段中，34 段 Completed、16 段 Failed 有实际分数；1 段 NotAttempted 没有分数。失败中的零分保留，无分数录像仅进入行为与覆盖统计。

这里的测试是 **held-out recordings（留出录像）**，不是 held-out participants（留出参与者）。同一人的其他录像可以出现在训练集中，当前结果不能证明对新参与者的泛化。每任务测试集为 5 人，每人一段录像；两个任务合计涉及 7 个不同参与者。

在这批实际导出中，测试录像的 `paired_n` 与其真人主分析 `valid_n` 一致：共同模型帧条件没有进一步削减已经满足 gaze、target、DLC 条件的有效帧。因此不应再假设本批结果一定额外丢失了开头约 1.3 秒；是否缺帧应以当前审计为准。

### 2.3 本次测量的是“预测期望点的区域占用”

每帧 target 是所有有效 target 点的算术平均中心；双侧 gripper 以 DLC 点为中心取圆盘并集。原始 `probability` 先归一化，再对网格坐标求期望，换算为一个浮点像素点。报告的模型 occupancy 是这个点落入区域的时间比例，**不是概率热图在区域内的质量积分**。双峰热图的期望点可能位于两个峰之间，这会影响区域命中，故结论应限定在当前解码方式下。

四类互斥状态为：T=target-only、P=gripper-only、O=overlap、N=other。重叠只计一次，四类占用之和为 1。

- `L_target = L_T + L_O`，`L_gripper = L_P + L_O`：分别回答“是否靠近 target / gripper”；二者不能直接相加当作总关注率。
- `D = L_T + L_P`：能区分 target 与 gripper 的独占区域占用。
- `C = L_T / D`：在两个独占区域之间的相对 target 偏好；D=0 时为 NA。**C 高不等于 target 占用高，也不等于驻留长。**
- `C_U = a_T / (a_T+a_P)`：按实际区域面积给出的相对偏好参照；`C_excess=C−C_U`。
- `E_target=L_target−(a_T+a_O)`、`E_gripper=L_gripper−(a_P+a_O)`：超出均匀空间面积参照的绝对占用。

例如 Task A 的 spd_zero_shot 全任务 C=0.783，看似接近真人 0.750；但 D 只有 5.30%，target 占用只有 4.27%。这表示少量独占区域命中偏向 target，不能据此称模型“复现了 target locking”。

trial 内按有效时长加权，参与者内按 trial 等权，参与者之间等权。表中的 C 是各 trial / 参与者 C 的均值，不能从已经平均的 target 和 gripper 两列反算；NA 导致可估计样本不同时，更不能直接相减两个非配对均值。所有直接模型误差均来自已保存的配对误差表。

|---|---|---|---|---|---|---|---|
| A | 全任务 | 24.89 | 9.45 | 2.73 | 0.767 [0.702, 0.828] | 0.334 | 11 |

| A | Transfer ring（转移环） | 25.07 | 6.62 | 1.25 | 0.794 [0.730, 0.856] | 0.336 | 11 |
| A | Place ring（放环） | 42.89 | 15.56 | 7.59 | 0.792 [0.716, 0.861] | 0.324 | 11 |
| C | 全任务 | 24.60 | 23.28 | 11.80 | 0.514 [0.442, 0.593] | 0.280 | 11 |

| C | Wrap（绕 gripper） | 28.24 | 29.13 | 19.02 | 0.468 [0.382, 0.563] | 0.217 | 11 |
| C | Cinch（拉紧） | 24.09 | 3.55 | 0.00 | 0.842 [0.704, 0.950] | 0.350 | 6 |
| C | Thread（穿线） | 11.13 | 10.50 | 2.72 | 0.536 [0.338, 0.735] | 0.329 | 8 |

**Task A：接近与精细操作阶段的关注分配不同。** Reach 的 target 占用为 12.38%，Place 为 42.89%；Grab 和 Transfer 介于二者之间。C 在 Reach 为 0.632，在另外三个阶段约为 0.79–0.80。可见接近阶段有较多 other 注视，进入抓取、转移和放置时，独占区域中的注视更偏向目标。但这是阶段条件下的空间分布，不能仅凭该表推断眼动先于动作。

**Task C：Wrap 的重叠是解释的核心。** Wrap 的 target、gripper 分别为 28.24%、29.13%，其中 overlap 已占全部有效时间的 19.02%。C=0.468 略低于 0.5，但面积参照 C_U=0.217，仍有明显超额 target 偏好。把 C<0.5 简化为“偏器械所以不熟练”既忽略面积，也忽略目标与 gripper 的空间耦合。

**Cinch 的高 C 不等于高质量证据。** 全量 C=0.842，但独占 gripper 占用很少，overlap 在当前保留片段中接近 0。该结果与“拉紧时必然高度重合”的预期不同；它说明当前标注中心和当前可用片段的几何状态，不能用任务直觉替代数据，也不能反过来用少量保留片段证明所有 Cinch 都如此。

整体上，两任务全量 target 超额占用分别约为 24.30 和 24.00 pp，说明相近的绝对 target 注视并非圆盘面积造成。主要差别是 Task C 有更多 gripper 与 overlap 注视。这里的 gripper 区域仅覆盖双侧跟踪点附近，器械杆和部分 gripper 边缘可能落入 other；结论应称“gripper 邻域关注”，不应泛化为整个器械。

## 8. 逐帧命中、Brier 与参照模型

### 8.1 为什么 occupancy 接近仍可能逐帧错得很多

两个轨迹可在相同时间比例上命中 target，却在完全不同的帧命中。本次模型已经解码为单点，target / gripper 预测事件为 0 或 1，因此事件 Brier 恰好等于时间加权的命中不一致率。它衡量事件一致性，不是原始概率热图的校准质量。

## 10. 驻留与 target↔gripper 切换

驻留使用 120 ms 最低时长；直接切换和仅经过连续 overlap 的间接切换分别计算，按有效分钟归一化。两端 T / P 驻留均须至少 120 ms，中间 overlap 片段不要求同样的最低时长。缺失、阶段 / occurrence 边界等会中断序列；满足条件的边界截断驻留仍纳入，其截断计数另外保存。本节的“驻留”是点停留于随时间变化区域的连续片段，不是经过独立眼动算法识别的生理 fixation。

平滑情景同时允许最多 100 ms 的短缺失插值，并在 41 Hz 网格上用三样本居中平均，再回映到原始时间；因此它既改变 gaze 位置，也可能改变有效帧。模型期望点没有做同样的平滑，不能把主分析与该情景的所有差异单纯归因于同帧位置去噪。具体插值比例保存在 coverage.csv。

全量 C / Reach string 的 gripper–分数点估计在六种情景均保持正向，但证据强度不同：主分析 ρ=0.624，25 px 为 0.587，100 px 为 0.569，严格 DLC 条件下为 0.477、区间 [−0.146,0.877]。半径变化或严格 DLC 筛选后的区间可跨零，且有效支持改变；这项探索性信号仍需要更多完整、可靠的 gripper 跟踪来验证。对于全任务 C–分数关系，改变阈值也没有形成两个任务一致、稳定的正相关。

五人测试集的相关和模型事件排名也依赖半径。Task A 真人 C–Score 从 25 / 50 px 的 0.900 降至 100 px 的 0.200；Task C single_task 从 50 px 的 −0.707 变为 100 px 的 +0.354。主半径 target Brier 最低的是两任务的 all_ABCD，100 px 时变为 single_task；25 px 时 A 为 zero-shot、C 为 leave_out。这进一步限制了按单一阈值宣布最佳模型或技能相关的做法。

另一方面，两任务全量真人在六种情景中的 C_excess 均为正，区间均高于零。即使单独放大 gripper 后 C 降到 A=0.403、C=0.113，各自 C_U 也降至约 0.094、0.042。因此“高于相应面积参照的 target 分配”比“C 是否超过 0.5”更适合跨区域大小解释，但不等同于与表现存在正相关。

Task C 的绝对 target 占用下降 8.04 pp [−14.14,−2.57]；gripper 增加 5.37 pp 的点估计对应跨零区间，overlap 的变化为 −2.07 pp [−7.98,3.28]，也没有明确方向。因此不能写成“更多 overlap 导致分数提升”。当前只测得部分行为量与分数随轮次并行变化，没有检验这些变化本身的相关或因果效应。

Task C 还有一项支持差别：占用指标第 1/3 轮使用 18/15 段录像，Score 使用 18/14 段；User8 第 3 轮有一段无分数录像。两类指标虽然都有 11 个配对参与者，其轮均值的 trial 集合仍不完全相同。轮次还可能伴随成功率、时长、阶段构成和可用标注片段变化；全任务变化不能直接归因于固定阶段内的策略改变。

阶段上，Task C 的 Reach string 和 Wrap 的 C 分别下降约 0.243、0.226；Reach string 的 target 占用下降 11.34 pp、gripper 增加 8.26 pp，其区间均支持相应方向。Thread 的 C 反而提高约 0.225，但只有 3 人且这些配对录像的分数变化为零。分阶段表所用分数仍是同一 trial 的总体 Score，并不是阶段专属分数。

Task C 全任务 C 的下降在 25 px、100 px 和平滑情景中保持，变化分别约 −0.192、−0.146、−0.228，区间都低于零；DLC≥0.9 时区间跨零。可说这一轮次变化在检查的空间半径范围内保持，不能称对所有质量筛选均稳定。

这种“个体内随轮次改变”与上一节“参与者之间均值相关”是不同统计问题，二者方向不一致并不构成计算错误。它提示必须区分横断面差异和练习过程。

## 13. 适合写进论文的结论与当前边界

### 13.1 证据支持的表达

- 在当前 50 px 容差及有效标注条件下，真实 gaze 在 Sea Spikes 中表现出较高的独占 target 偏好；Knot-tying 的 target 与 gripper 关注更耦合，尤其 Wrap 的 overlap 较高。两个任务的绝对 target 占用接近。
- 当前预测期望点在 Task A 普遍低估 target 占用；Task C 的 single_task 边际占用最接近真人，但均值接近不能保证个体或逐帧一致。spd_zero_shot 的某些相对偏好指标较接近真人，与其较低绝对命中、较差 Task C 逐帧 target 一致性同时成立。
- 全量 novice 数据中，全任务 C 与 SimNow 分数没有显示稳定的正向单调关系。Grab 的 target 占用、Reach-string 的 gripper 占用有值得复核的阶段性信号。
- 技能练习中的分数提高没有对应两个任务一致的 C 提高；C 应与绝对占用、D、overlap、面积参照、驻留及阶段共同解释。

### 13.2 当前不能支持的表达

- 不能说“专家看目标、新手看器械已被证实”：本分析仅有 novice，且 Task C 的一些结果与这种单一规则不同。
- 不能说某一个模型全面胜出：occupancy、C、逐帧事件一致性和表现相关考察不同方面，排序不同；许多区间很宽。
- 不能将 5 人测试子集的强相关推广到 11 人或新参与者，不能把 C=1 或平均误差接近 0 当作稳定行为恢复。
- 不能把 Thread / Cinch 的少量有效片段、DLC≥0.9 的稀疏结果、经验 bootstrap 的窄区间当成充分样本支持。
- 不能把空间分布或相关解释为因果机制，也不能把本次单点指标的 BSS 推广到概率热图的全部性能。

这份报告最稳妥的整体判断是：**Target Locking 提供了有用的阶段行为描述和模型误差诊断，但当前尚不是一个跨任务、跨参与者稳定预测 SimNow 表现的单一指标。**
