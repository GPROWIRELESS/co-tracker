## 5. 本轮文档修订的审阅结论

| 旧问题 | v3修订要求与当前处理 |
|---|---|
| 状态码筛选及旧数据混用 | 当前数值均切换v3；gaze不再按valid筛选；仅保留5个正式情景。 |
| 摘要与详细版C范围脱节 | 两份详细报告新增A whole/C reach string专表，另保留C whole和各阶段。 |
| 未披露范围改变模型对比 | 当前审阅表明确列出reach、whole、wrap配对差；摘要须保留该差别。 |
| 探索性相关缺少敏感性 | 报告补充5情景相关/轮次证据；摘要明确半径变化下的不确定性。 |
| 失败零分未披露 | 说明Failed=0、成绩缺失和轮次支持；没有假定完成者敏感性已经执行。 |
| 边缘CI二分化 | 保留准确区间，同时说明小样本、多重探索和范围/半径敏感性；不虚构端点误差。 |
| 概率得分被升级为架构证据 | 区分输出表示比较与架构/记忆消融，保留专家参照和效率评估缺口。 |

| 旧版图片混入当前解释 | 当前逐图解读改用v3图片；历史版本仅作历史链接。 |


**使用判定：** 可作为本次 v3 结果的解释与论文写作依据；目标锁定尚非经过验证的单调技能指标，模型的专家式 gaze、架构必要性和数据效率仍未由本目录验证。本文不沿用旧稿的主观百分制评分，也不将更新文档等同于完成新增科学验证。
