## 范围、筛选规则与核心结论

仅纳入映射 JSON 中 `task_name` 为 A/C、`observer_skill=novice` 且 `src_skill=novice` 的记录，所有 split 均可纳入。Task A（Sea Spikes）为 7 条观看、7 名观看者；Task C（Knot-tying）为 9 条观看、8 名观看者。两任务人数不可相加当作独立总人数。统计参与者使用 `meta.observer`，源操作者使用 `meta.user`，两者不互换。

分析分支固定为 `analysis_branch=observed_gaze / source=gaze / scope=real_all`。观看者 gaze 仅取 passive `gaze_npy_path` 的 `gaze_x`、`gaze_y`；源 NPY 只提供阶段与目标标注，不将源操作者 gaze 当作观看者 gaze，不使用源 gaze 有效性筛帧。主分析没有模型共同有效帧限制。

主条件 target/双侧腕部邻域半径均为 50 px。target 为有效标注槽位均值附近圆盘，PSM 为左右 DLC 腕部/铰接点圆盘并集。两者不是完整物体 mask，也不是已验证的夹爪尖端。每条观看内按原生时长加权，观看者内各可估记录等权，组内观看者等权。

Task A 四阶段整体的 `L_target` 为 **9.78 [5.92, 13.63]%**，`L_gripper` 为 **4.40 [2.42, 6.55]%**，`C` 为 **72.04 [64.32, 79.20]%**。Task C 四阶段整体相应为 **8.69 [5.95, 11.88]%**、**17.02 [12.25, 22.13]%**、**25.29 [16.47, 33.98]%**。

论文范围保持参考摘要的定义：A 四阶段整体，C 仅 reach string。C reach string 的 `C` 为 **18.55 [10.96, 25.38]%**，`C_excess` 为 **-13.63 [-21.12, -7.08] pp**；在 main 定义下呈腕部相对优势，并且独占目标偏好低于均匀面积基线。C whole 的 `C_excess` 则为 -2.23 [-9.84, 5.47] pp，区间跨 0，不能用 whole 替代 reach string。

**本数据支持任务与阶段相关的注视分配描述，不能验证目标锁定是“越高越好”的技能指标，也不能据此断言 passive 优于或劣于 active。**

## 可支持的结论与使用限制

1. 在本批存储规范映射与 main 50/50 px 定义下，A whole 呈目标相对优势，C reach string 呈腕部相对优势；这是行为分配描述。
2. 高 `C` 不意味着高 `L_target`，面积修正也不是技能修正。应同时报告 `D`、`L_O`、`C_U` 和实际支持。
3. 小样本、阶段覆盖不均、目标语义、历史坐标端点裁剪、未独立验证的物理显示时序/viewport 限制解释。观察者 bootstrap 没有另建源操作者/刺激视频层级，不能消除刺激差异或建立对任意源视频总体的外推。
4. 未校正多重比较，未增加 p 值、t 检验、置换检验或 BH/FDR。CI 跨 0 不证明效应不存在，不跨 0 也不单独证明因果或普遍规律。
5. 没有观看者本人表现和练习轮次、没有专家组、没有模型训练对照。不能验证专家式注视、被动学习收益或新手数据替代专家监督；不能将 GT84 主动操作数字直接当成匹配对照。

## 指标与计算方法：完整阅读字典

### 命名一致性与分析对象

沿用 GT84 字典的 `L_T/L_P/L_O/L_N`、`L_target`、`L_gripper`、`D`、`C`、`B`、`area_*`、`C_U`、`C_excess`、`E_target/E_gripper`、`B_excess`、`dwell_T/P/O_ms`、`direct_rate/via_rate`。不为 passive 的同义变量另造符号。Task C 是任务名；代码字体 `C` 是目标偏好指标，二者必须区分。

| 字段/符号 | 统一含义 |
| --- | --- |
| `participant` / n | 本批观看者 `observer`，不是源操作者 `user` |
| `clip_key`、`recording_id`、`content_id` | 唯一观看记录标识；`source_content_id` 才是源视频标识 |
| `real_all` | 所有符合本次筛选与输入条件的真实观看者记录，不指映射中的全部 122 条 |
| `whole` | 本任务四个纳入阶段的有效支持合并 |
| T / P / O / N | 目标独占 / 腕部独占 / 两区域重叠 / 两区域之外 |
| `target` | 有效 `point_1` 至 `point_5` 槽位像素坐标的算术均值，以未取整中心建圆盘 |
| `PSM` / `gripper` | 双侧 DLC 腕部/铰接点圆盘并集；字段保留 `gripper`，中文统一称腕部邻域 |
| $q_{ir}$ | 第 i 帧真实 gaze 是否落在区域 r 的 0/1 指示，不是模型概率 |
| $w_i$、$V$、$W$ | 原生帧时间权重（秒）、联合有效帧集合、总有效时长 $W=\sum_{i\in V}w_i$ |
| $a_{ir}$、$A_r$ / `area_r` | 帧内区域面积占比、同支持下时间加权面积占比；$A_r=\sum_{i\in V}w_i a_{ir}/W$ |

### 时间权重、有效分母与层级汇总

按原始 `Frame_Number` 对齐精确 `video_ts`。只有原帧连续且 $0<\Delta t\le100$ ms 的相邻间隔，向两端各分配一半时间；在阶段切分前计算。不向首尾外推、不跨断帧补时，孤立帧权重为 0。因此 `valid_n>0` 不保证 `valid_s>0`。

每条观看、每阶段先计算指标，观看者内只对该指标可估记录等权平均，再对可估观看者等权平均。C 任务有一名观看者两条记录，也只占一个观看者权重。不可把所有帧/秒池化，或对全部 9 条 C 记录直接平均，代替报告组均值。

### 占用、偏好与面积修正

在 $W>0$ 时，$L_r=\sum_{i\in V}w_iq_{ir}/W$。面积按画面内所有像素中心 `(列+0.5, 行+0.5)` 精确计数，圆盘超界部分裁除、双侧腕部重叠去重，不用无限平面 $\pi r^2$ 代替。

| 保存字段 | 数学定义 | 解读 |
| --- | --- | --- |
| `L_T`, `L_P`, `L_O`, `L_N` | $L_r$，四项合计 1 | 互斥区域占用；N 不是无效帧 |
| `L_target` | $L_T+L_O$ | 含重叠的目标占用 |
| `L_gripper` | $L_P+L_O$ | 含重叠的腕部占用 |
| `D` | $L_T+L_P$ | 能区分目标/腕部的独占占用 |
| `C` | $L_T/(L_T+L_P)$，零分母为 NA | 独占区域内目标条件偏好；0.5 为两类独占占用相等 |
| `B` | $L_T-L_P=L_{target}-L_{gripper}$ | 原始净目标优势；单记录可估时 $B=D(2C-1)$ |
| `area_T/P/O/N` | $A_T,A_P,A_O,A_N$，四项合计 1 | 同支持、同时间权重下的均匀画面机会 |
| `C_U` | $A_T/(A_T+A_P)$，零分母为 NA | 加权面积之比，不是逐帧面积比的均值 |
| `C_excess` | $C-C_U$ | 超过面积基线的独占目标偏好 |
| `E_target` | $L_{target}-(A_T+A_O)$ | 目标占用超出自身面积机会的幅度 |
| `E_gripper` | $L_{gripper}-(A_P+A_O)$ | 腕部占用超出自身面积机会的幅度 |
| `B_excess` | $L_T-L_P-A_T+A_P=E_{target}-E_{gripper}$ | 面积修正净目标优势 |

这些是单记录定义；组 `C` 是个体指标的分层均值，不等于组 `L_T` 除以组 `D`。组 `C_U` 同样不能由组 `area_T/P` 再相除替代。$B=D(2C-1)$ 不可不加区分地套到组均值；线性等式在支持相同的条件下才沿聚合保留。CI 直接对各指标 bootstrap，不能拿两条 CI 端点相减或相除制造新 CI。

### 时序字段与 NA

| 保存字段 | 定义 |
| --- | --- |
| `valid_n` | 联合条件满足的原生帧数 |
| `valid_s` / `valid_seconds` | 占用/时序分析的有效原生秒数，本 observed-gaze 分支对应一致 |
| `dwell_<state>_median_s` | 每条观看中观察时长 ≥120 ms 的同状态连续 run 中位数（秒）；无合格 run 为 NA |
| `dwell_T_ms/P_ms/O_ms` | 对应 target_only/psm_only/overlap 的上述中位数×1000，组值为分层平均 |
| `dwell_<state>_n`、`dwell_<state>_n_censored` | 合格 run 数、其中触及边界/缺失而截断的数量 |
| `all_<state>_runs`、`all_<state>_runs_censored` | 不设 120 ms 门槛的全部 run 数及截断数 |
| `direct_count` | 相邻且两端均 ≥120 ms 的 T→P 或 P→T 次数，两方向相加 |
| `via_count` | T→O→P 或 P→O→T 次数，两端 T/P 均 ≥120 ms，中间恰为一个连续 O run，O 不要求 ≥120 ms |
| `direct_rate` / `via_rate` | 各自计数除以该观看有效分钟数，再作分层平均；有效时间为零则 NA |
| `C_reason` | `zero_exclusive_occupancy`：独占分母为0；`no_valid_frames`：有效分析时长不可用 |
| `dwell_T_reason/P_reason/O_reason` | 说明无有效观察或没有达到 120 ms 的 run，不能用零驻留代替 |

### 置信区间与可估支持

保存的区间沿用 `ParticipantBootstrap`：10,000 次观看者有放回抽样，seed=42，`SeedSequence([42,n])`，取 2.5/97.5 百分位。n<2 不生成均值 CI，`bootstrap_defined=bootstrap_undefined=0` 表示没有执行，而非执行后全部通过。无观察不能填零；有有效时间而没有合格切换可以为零。CI 不包含硬件同步误差校正，也不表示模型泛化性能。

本分支无 64 样本概率 MC、三种模型 decoder、`paired_test`、Brier/BSS、模型混淆/排名或训练静态参照；不输出 `GT_smoothed` 诊断。`smooth` 只是本报告的真实 gaze 敏感性，不能与模型评测中的 `GT_smoothed` 混用。
