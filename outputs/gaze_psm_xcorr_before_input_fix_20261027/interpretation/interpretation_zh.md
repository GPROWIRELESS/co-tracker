# 现有 gaze/PSM xcorr 输出的解释

本报告只解释现有 outputs/gaze_psm_xcorr 的运行结果，没有修改、补算或覆盖原始统计结果。

**结论：存在任务、工具和阶段相关的轨迹时延，但现有输出不能证明注视普遍提前到达 PSM 随后到达的同一位置。以下数值均为初步结果。**

## 数据完整性

- 计划纳入 84 条记录：Task A 33 条，Task C 51 条，同一批 11 位新手。
- 70 条提取成功；14 条因 raw gaze 时间戳含科学计数法、代码直接 int() 解析失败而被排除。
- 另有 4 条虽标记提取成功，但状态码为 2.0，而配置仅按字符串接受 2，导致 gaze 全部过滤。这些记录原始数据中存在有效 gaze，并非数据本身没有 gaze。
- 全任务位置 xcorr 实际纳入 Task A 27/33 条、Task C 39/51 条，共 66/84 条；两任务均仍覆盖全部 11 位新手。
- 新手内先对记录曲线做 Fisher-z 平均，再对新手等权平均。组延迟来自组曲线峰值，不是 66 条记录峰值的平均。
- 配置：41 Hz、±2 s 搜索、80 ms 平滑、1000 次新手 bootstrap、100 次异人同任务配对。空间接近阈值为探索性的 50 px。

## 同位置验证与速度分析

Task A 右工具虽有 +341 ms 峰值，但距离仅由零滞后的 293.5 px 变为 289.8 px；50 px 内比例由 4.45% 变为 4.39%。其他全任务条件的接近比例也仅约 1.4%–12.0%。因此不能将位置相关峰值解释为已经证实“注视先落到同一目标位置”。

较大空间差异可能与工具整体质心相对尖端的偏移、gaze 图像注册、或实际观察对象不同有关；现有输出不能区分这些原因。

全任务速度 xcorr 峰值 r 仅约 0.019–0.049；A 的时延区间均跨 0，C-L 也跨 0，C-R 为负。因此速度分析不支持普遍、稳定的运动领先。

本次输入是 raw gaze，未检测 fixation；工具位置是 mask 质心。因此结果针对 gaze 与质心轨迹，不能直接称作 fixation 到工具尖端目标的首次到达时间差。

## 可用于结果部分的表述

> 在现有可用记录中，以 11 位新手为独立分析单位，gaze 与 PSM 质心的位置轨迹存在任务和阶段依赖的时间关联。Task A 右 PSM 的组峰值显示约 341 ms 的 gaze 领先，而 Task C 右 PSM 显示约 171 ms 的 gaze 滞后；两任务配对峰值差约为 −512 ms。Task A transfer 阶段呈约 0.56–0.66 s 的正时延，但该结果明显依赖跨阶段配对。由于空间接近比例较低、输入尚非 fixation，且 18 条记录因解析或状态码问题未有效纳入，现阶段不能得出 gaze 普遍先到达 PSM 将要到达的同一位置，也不能给出统一提前时间。

## 需要优先解决的事项

1. 修复科学计数法时间戳解析，以及 2/2.0 状态码数值等价处理；重算受影响记录，并重新生成全部组统计。
2. 核对 gaze 与图像的空间注册、Y 方向，以及 mask 质心是否代表问题中的工具位置；如研究尖端目标，应另用尖端轨迹。
3. 在预先定义的空间容差和分析配置下复核距离、平滑敏感性、边界峰和稀疏阶段。
